# Nikon 1 J5 C1.01 — patched v07

[English](README.md) | 简体中文 · [返回项目首页](../../README.zh-CN.md)

patched v07 为 J5 添加了纯机械镜头的对焦放大、A 档拍摄和自动 ISO 功能，不需要蒲公英芯片或电子接环。仅适用于 Nikon 1 J5，已测试从 C1.01 刷入。

## 新增功能

- **M、A 档对焦放大**：按 OK 进入放大，方向键调整放大位置。
- **放大持续保持**：不再自动超时退出；半按快门或按 OK 退出。
- **A 档拍摄**：在镜头上调整光圈，相机自动选择快门时间，可以正常拍照、保存。
- **A 档自动 ISO**：选择 Axxx 后，ISO 会随亮度变化；固定 ISO 也可正常使用。

光圈仍通过镜头光圈环调整。屏幕可能不显示「按 OK」提示或光圈值，不影响使用。

## 下载

在 [J5 patched v07 发布页](https://github.com/XCQi/Nikon-1-custom-firmware/releases/tag/j5-patched-v07)下载所需文件：

| 文件 | 用途 |
|---|---|
| `J5_0101_patched_v07.bin` | 安装自制固件 |
| `J5_0101_stock_restore.bin` | 恢复原厂功能 |

卡中只保留本次要刷入的一份固件，避免混用。

## 刷机步骤

准备充足电量的电池和读卡器，先备份卡上的照片。如果相机目前为 C1.00，先按[尼康官方说明](https://downloadcenter.nikonimglib.com/en/download/fw/234.html)更新至 C1.01。更新过程中不要断电或拔卡。

1. 下载 `J5_0101_patched_v07.bin`，复制到存储卡根目录。
2. 将卡装回相机，开机后进入「设置 → 固件版本 → 更新」。
3. 按屏幕提示完成更新并关机。
4. 删除卡上的升级文件，再开机使用。

装上纯机械镜头后，在 M 或 A 档按 OK 即可放大对焦。需要自动 ISO 时，在 ISO 菜单中选择 Axxx；可以通过亮暗场照片的 EXIF 查看 ISO 是否变化。

刷机后版本页仍显示 C1.01，更新入口也可能保留，按实际功能确认安装结果即可。

## 恢复原厂功能

下载 `J5_0101_stock_restore.bin`，复制到卡根目录，按相同的刷机步骤更新。完成后删除升级文件，再开机。对焦放大、A 档拍摄和自动 ISO 等改动会被移除。

恢复包已实测可用。它保留了原厂功能代码，只调整更新识别和校验，以便在 C1.01 上再次刷入；未经修改的官方 C1.01 文件可能因版本相同而无法更新。恢复后版本页仍显示 C1.01。

此方法要求相机能正常开机并进入更新菜单，不能用于修复无法开机的相机。

## 使用范围

以上功能已在一台 J5 上实测，固定 ISO 和 M 档拍摄也正常。电子镜头组合、各自动 ISO 上限和长期可靠性尚未全面测试。

本版不修改 S、P 档或 4K 视频规格，也不能用于其他 Nikon 1 机型。这是非官方实验固件。
