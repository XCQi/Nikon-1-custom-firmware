# Nikon 1 J5 — v7

[English](README.md) | 简体中文 · [项目首页](../../README.zh-CN.md)

面向纯机械／无 CPU 镜头，不需要蒲公英芯片或电子接环。**只适用于 Nikon 1 J5；已测试的基础固件为 C1.01。**

## 自定义功能

- **M / A 档对焦放大**：按 OK 进入，方向键移动放大位置。
- **持续放大**：不会自动超时；半按快门或按 OK 退出。
- **A 档拍摄**：能拍照和存片，在镜头上调整光圈，相机自动选择快门时间。
- **A 档自动 ISO**：支持随亮度变化调整 ISO，也可以选择固定 ISO。

光圈仍由镜头光圈环调整。屏幕可能不显示“按 OK”提示或光圈值，不影响以上功能。

## 下载

[J5 v7 发布页](https://github.com/XCQi/Nikon-1-custom-firmware/releases/tag/j5-v7)，下载所需附件：

| 文件 | 用途 |
|---|---|
| `J5_v7.bin` | 安装 v7 增强功能 |
| `J5_stock_restore.bin` | 恢复原厂功能 |

**两份文件刷入前都要改名为 `J5_0101.bin`。一次只复制需要刷入的一份，避免混用。**

## 刷入 v7

1. 给电池充足电，备份卡上照片，准备读卡器。如果目前为 C1.00，先按[尼康官方说明](https://downloadcenter.nikonimglib.com/en/download/fw/234.html)更新到 C1.01。
2. 下载 `J5_v7.bin`，改名为 `J5_0101.bin`，复制到存储卡**根目录**。
3. 插卡开机，进入 **设置 → 固件版本 → 更新**，按屏幕提示操作。期间不要断电或拔卡。
4. 完成后按提示关机，删除卡上的升级文件，再开机。

使用纯机械镜头，在 M/A 档按 OK 应能持续放大；半按或 OK 可退出。A 档应能拍照和保存；需要自动 ISO 时选择 Axxx，可在亮暗场拍摄后查看照片 EXIF 的 ISO 变化。

版本页仍显示 **C1.01**，更新入口也可能仍存在，这是预期表现；按实际功能确认成功即可。

## 恢复原厂功能

恢复包已实测成功。

1. 下载 `J5_stock_restore.bin`，改名为 `J5_0101.bin`。
2. 用它替换卡根目录的升级文件，按上面的机身更新步骤刷入。
3. 完成后删除升级文件，再开机。纯机械镜头的增强功能会被移除，恢复原厂限制。

请用本项目的恢复包：未经修改的官方 C1.01 可能因版本相同而无法再次刷入。恢复包只对更新识别和校验做必要调整，功能代码保持原厂状态，版本页仍显示 C1.01。

回退要求相机可以正常开机并进入更新菜单，不是无法开机时的救援方法。本次恢复后再刷 v7 的完整往返尚未实测。

## 已测试与限制

目前验证来自同一台 J5：上述功能正常，固定 ISO 和 M 档回归正常，恢复原厂功能成功。

空 FT1 的 A 档自动 ISO 仍不浮动。电子镜头组合、各自动 ISO 上限及长期可靠性尚未完整测试。本版不包含 S/P 解锁或 4K 修改，也不适用于其他 Nikon 1 机身。这是非官方实验固件。
