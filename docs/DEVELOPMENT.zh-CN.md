# Nikon 1 自制固件开发记录：J5 v7

[English](DEVELOPMENT.md) | 简体中文

## 范围与复现

本篇供开发者阅读；普通用户直接下载 BIN，按安装教程更新即可。补丁仅适用于精确 J5 C1.01 输入，不适用于其他 Nikon 1。本篇公开实现思路和关键地址；完整源码、构建工具和详细分析材料在内部交接中保留。

## 封装与地址

主镜像从解码包偏移 0x50 开始；本篇低地址代码满足 runtime=image offset+0x80000。高 RAM 搬运段须另外映射。包前 32 字节不变，后续字节按三张 256 字节表异或：raw[i] XOR t0[i&255] XOR t1[(i>>8)&255] XOR t2[(i>>16)&255]。同一变换用于重新封包，三张表来自历史 Firmware1.cs 工具。所有补丁字节指解码后的内容。

## 更新识别与运行版本

主镜像 +0x800 的 Ver.1.0100 改成 Ver.1.0101，即包 0x859 的 30→31；image+0x16490C 和 +0xA33CF0 的运行版本默认字段不变。A/B 探针表明只改外层 entry 名无入口，只改 image 头有入口；静态比较器与重复更新支持细分候选版本方案。版本页仍显示 C1.01，更新入口可能保留。菜单出现只证明预检通过；功能与恢复实测另行证明刷入结果。这不是任意高版本降级方案。

## MF 放大入口

image 0xAC71E / runtime 0x12C71E：3FD0→C046，以 Thumb NOP 移除 CameraNonCPULens 路径的阻挡。早期错误的 ShootSequenceAct 修改已撤销；image 0xAC8D6 保留原 08D0。屏幕 OK 提示属于另一条 UI 路径，没有补上。

## 持续放大

mf_timer_am.s 放在 image 0x2C0，text 228 字节，保留至 0x3AF。hook image 0x4C8A78 / runtime 0x548A78，B1F699FF032892D1→004B1847C1020800，绝对地址跳板进入 Thumb 0x802C1，避免老式 Thumb BL 距离限制。仅 timer=3 且属性读取全部成功时匹配目标：M 的 (0x13,0x2BB)=(4,3)，A=(3,2)，并且 0x3EE=0、0x419!=5、0x2A2!=1。匹配则抑制超时，否则保留原计时处理；非到期／到期续接 0x5489A6/0x5489F2。半按和 OK 的退出路径保留。

## A 档警告与拍摄

image 0x15A78A / runtime 0x1DA78A：07→41 处理警告，但单独修改只能测光，不能拍照。拍摄 hook image 0x15FD02 / runtime 0x1DFD02：032803D0→A0F655FB，BL 到 0x803B0。a_capture_c2.s 为 196 字节，位于 image 0x3B0..0x473。保留有效模式 3 原放行；新增模式 2 还要求 hook 原 C2 字节为 0，公开属性读取 0x13=3、0x3EE=0、0x419!=5、0x2A2!=1、0x2BB=2 全部成功。放行／原续接为 0x1DFD0E/0x1DFD06。保存寄存器及栈，不重写 AE 或伪造镜头光圈。

## A 档自动 ISO

原 ISO 生产链 runtime 0x17A5C2 调 0x178B2C 获取配置，再调 0x17A4D0 做第二阶段处理并写 0x2C9。两处镜头状态钳制把自动枚举 2/3/4 变为 0x0F：一处检查 0x3EE，另一处检查 0x3F8/0x3F9。v7 在 image 0xFA5EC / runtime 0x17A5EC 用 022803D0→05F748FF，进入 0x80480；在 image 0xFA518 / runtime 0x17A518 用 022C03D0→05F7CAFF，进入 0x804B0。a_auto_iso.s 为 image 0x480..0x57F 的 256 字节。

## 属性接口与例外范围

ISO 例外仅匹配自动枚举 2/3/4，并要求当前 staged 视图读取 0x13=3、0x419!=5、0x2A2!=1、0x3EE=0 全部成功；其他 ISO／HDR 等原处理保留。成功码为 0xF0000000。公开对象 factory 0x2CE0A9，getter 在 vtable+0；staged 视图 getter 在 +4，不能混用，也不应以可能尚未同步的公开状态代替 staged 状态。0x0F 是枚举，其到 ISO 数值的转换没有单独完整追踪。

## 代码空洞

原 image 0x2C0..0x7FF 为零。分析核对了启动入口、附近 literal、已找到的复制／清零范围及主镜像写入起点，三段 helper 不重叠。实机 v3/v5/v7 生效支持装载与执行，但静态搜索不是所有间接引用的穷尽证明。扩大空洞使用范围时须重新检查。ARM/Thumb 状态、函数指针低位、完整指令边界、寄存器、条件码、LR、栈对齐及续接语义均需验证。

## 双层 CRC 与恢复包

使用 binascii.crc_hqx(data,0)，大端存储。embedded CRC 在解码包 0x175A6E0..E1，覆盖 [0x50,0x175A6E0)；outer CRC 在 0x175A6E2..E3，覆盖 [0,0x175A6E2)，含已写入的内层 CRC。追加后两段 syndrome 均为 0，之后再封包；其他尾部字节保持原样。恢复包从原厂重新生成，仅包 0x859 的 30→31 和内层 CRC 两字节变化，outer CRC 恰好不变，功能代码全部原厂。已实测刷回成功，不是变砖救援。

## 验证和移植边界

离线模型分别覆盖拍摄 5,187、计时器 79,380、自动 ISO 38,400 个组合；报告随内部交接保留。它们执行相关指令并模拟属性接口，不模拟传感器、真实 AE 或刷写安全。实机反馈范围见 J5 使用说明。空 FT1 自动 ISO 未浮动，不证明对所有电子镜头零影响。其他 Nikon 1 必须重新确认封装、地址映射、指令集、属性契约、启动、更新和目标路径，不能沿用 J5 地址或只换型号名。


## 发布文件与证据边界

用户直接从 Release 下载 BIN，不需要构建。内部构建器从精确官方输入出发，校验原字节、改动范围、双层 CRC 与最终 SHA-256；三段汇编已重新编译核对。离线模型不是整机仿真，实机反馈来自单台 J5，未测范围见 [J5 说明](../cameras/J5/README.zh-CN.md)。
