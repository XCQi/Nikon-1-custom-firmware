# Nikon 1 Custom Firmware

English | [简体中文](README.zh-CN.md)

This project adds features that are not available in Nikon's stock firmware. It currently supports the J5, including mechanical-lens features, FT1 improvements and shorter interval shooting.

## Supported cameras

| Camera | Version | Added features | Guide |
|---|---|---|---|
| Nikon 1 J5 | patched v11.1 | Assignable Wi-Fi/Delete buttons, MF magnification controls, language-menu unlock, mechanical-lens support, partial FT1 AF-point unlock, 1-second intervals, and FT1 lens compatibility preview | [J5 guide](cameras/J5/README.md) |

FT1 features have compatibility limits, including a known touch-shutter focus wait. Read the [J5 guide](cameras/J5/README.md) before installing.

## Download and installation

Download the BIN files for the camera from [Releases](https://github.com/XCQi/Nikon-1-custom-firmware/releases), then follow the camera guide. No compilation or patching is needed. Each camera folder contains features, installation steps, restoration instructions and a changelog.
